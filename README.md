## Overview 
This project is an interactive Sales Dashboard created in Microsoft Excel to analyze supermarket sales data. The dashboard provides insights into sales performance, customer behavior, product categories, payment methods, and city-wise revenue using Pivot Tables, Pivot Charts, KPI cards, and Slicers.

## Dashboard Features 
- Total Sales, Tax, Quantity Sold, and Unit Price KPIs
- Branch-wise sales comparison
- Product line performance analysis
- City-wise sales and gross income analysis
- Customer type analysis (Member vs Normal)
- Dynamic filtering using Slicers
- Interactive visual dashboard

## Key Insights 
- Health and Beauty is a major revenue-generating category.
- Mandalay contributes the highest sales among selected cities.
- Member customers show higher spending compared to normal customers.
- Dynamic filters enable faster business analysis and reporting.

## Tools & Techniques 
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Data Cleaning
- Data Visualization

## Business Impact
- The dashboard transforms raw transactional data into clear visual insights, helping identify sales trends, customer patterns, and high-performing business areas. It supports faster and more effective data-driven decision-making.
